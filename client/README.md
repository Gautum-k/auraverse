# Auraverse (frontend)

Spotify-style music collaboration and artist networking platform.
React (Vite) + React Router + plain CSS. Data is mocked in `src/data.js`; the Node/Express/MongoDB backend plugs in next.

## Run
```
npm install
npm run dev
```
Open http://localhost:5173

## Pages
- `/` Home, `/search`, `/artist/:id`, `/collabs`, `/upload`, `/library`, `/playlist/:id`, `/queue`, `/login`

## Song management
Playlists (create, rename, delete, add/remove songs), play queue, likes, and edit/delete for your own uploads.
